## 📝 Описание проекта
Программа предназначена для работы с базой данных из 4000 записей. Программа выполняет динамическую загрузку данных, постраничный вывод, сортировку за один проход, быстрый поиск с формированием очереди, построение дерева поиска и статическое кодирование файла.


### Реализованный функционал (согласно варианту):
1. **Динамическая загрузка:** Чтение `.dat` файла в память в виде списка без дублирования данных.
2. **Постраничный вывод:** Отображение базы по 20 записей на страницу с возможностью прерывания.
3. **Сортировка (S = 4):** Упорядочение данных за один проход методом DigitalSort.
4. **Быстрый поиск:** Поиск по ключу в отсортированной базе, формирование очереди совпадений.
5. **Дерево поиска (D = 3):** Построение Дерево оптимального поиска (приближеный алгоритм А1) из элементов списка.
6. **Архивация (E = 4):** Сжатие файла статическим кодом Гилберта-Мура с расчетом энтропии и коэффициента сжатия.

*Особенность реализации: Строки обрабатываются как массивы символов (`array of char`), встроенные функции сравнения строк не используются. Код не содержит поясняющих комментариев согласно требованиям.*
